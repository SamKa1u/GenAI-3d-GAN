#   Comparing 3D-GAN Quality of 3D Object Generation From 2D Inputs

Traditional Convolutional 3D-GAN Generator vs ConvNeXt Generator

## Description

Implements 2 3D-GANs based on the paper Learning a Probabilistic Latent Space of Object Shapes via 3D Generative-Adversarial Modeling, testing the effectiveness of the modernized CNN model ConvNeXt which borrows principles from ViTs to outperform them.
